## ADDED Requirements

### Requirement: Use Lucide icons site-wide

The system SHALL use Lucide icons for all iconography in the site, replacing inline SVGs.

#### Scenario: Top navigation icons

- **WHEN** social icons render in the top navigation
- **THEN** they use Lucide icon components

#### Scenario: Contact page icons

- **WHEN** contact social icons render
- **THEN** they use Lucide icon components

#### Scenario: Home page section icons

- **WHEN** highlights or amenities render
- **THEN** their icons use Lucide components
